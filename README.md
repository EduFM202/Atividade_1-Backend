# 📝 $\color{yellow}{\text {Atividade 1 - A Nossa Missão: Lista 1 - Backend}}$

🎯Atividades

- Um cálculo de preço de produto com aplicação de 10% de desconto para compras a partir de R$ 200,00.
- Um sistema de verificação de aprovação baseado na média (≥ 6,0) e limite de faltas (≤ 15), utilizando o operador lógico &&.
- Uma tabuada (de 1 a 10) de um número específico utilizando a estrutura de repetição for.
- O processamento de um vetor (array) contendo 5 notas para calcular a média da turma, a maior e a menor nota.
- Uma função calcularIMC($peso, $altura) que retorna o IMC calculado e o classifica (Abaixo do peso, Peso normal, Sobrepeso ou Obesidade).
